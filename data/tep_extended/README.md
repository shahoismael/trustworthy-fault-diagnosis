# Extended Tennessee Eastman Process (Primary)
- Source: Rieth, Amsel, Tran & Cook (2017), Harvard Dataverse
- DOI: https://doi.org/10.7910/DVN/6C3JR1
- CSV mirror (easier): Kaggle `afrniomelo/tep-csv`
- Contents: 20 faults + normal, 500 simulation runs each, 52 variables, 3-min sampling
- Use: primary FDD benchmark; imbalance, rare/incipient faults, open-set, calibration
- Put downloaded files in `raw/`; windowed/normalized arrays in `processed/`.
