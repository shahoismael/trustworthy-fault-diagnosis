# IndPenSim — Industrial Fed-Batch Penicillin Simulation (Process diversity)
- Source: Goldrick et al. (2015/2019)
- Download: IEEE DataPort / industrialpenicillinsimulation.com (open)
- Contents: simulated fed-batch fermentation; batch bioprocess, many batches, faults/variability
- Use: generality beyond TEP (batch vs continuous); optional soft-sensor/quality track
- Put downloaded batches in `raw/`; processed arrays in `processed/`.
